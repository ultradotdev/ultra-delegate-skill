# Ultra Delegation 1.2.0-beta.1

An experimental proof of concept for frontier planning with bounded worker delegation, verification, and portable learning. Read the README disclaimer before use; this is not production-ready automation.

## Included

- Task-specific model, native thinking-setting, and prompt-profile comparisons.
- Host/provider boundaries, project exclusions, quality gates, and trust-but-verify learning reuse.
- Canonical evidence, sanitized exports, measured/estimated/unavailable reporting, and corrected cached/thinking-token accounting.
- Fresh-observation context checkpoints and local resource-policy simulations.
- Dependency-free helper, host templates, reproducible learning demo, installable skill and clean source archives with SHA-256 checksums.

## Evidence and limitations

- 78 tests pass locally; Python 3.10, 3.12, and 3.14 CI passed on the initial review snapshot.
- Maintainer-reported working use in Codex and Claude Code. Exact model/effort combinations are not exhaustively qualified.
- OpenCode and Cortex integration remain experimental. The learning demo is synthetic, not a model benchmark.
- Local execution remains disabled by default and unsupported even after opt-in: an enforcing runtime adapter has not shipped.
- No guaranteed cost savings, data protection, or resource isolation. Use a disposable/backed-up checkout and review agent changes.

The source archive omits the private development history. Install the skill ZIP, not the source ZIP, when copying directly into a host's skill directory. Existing personal/project evidence is not overwritten by installing the skill.
